# MagicSquare_XX

4×4 마방진(Magic Square)을 다루는 학습·설계 프로젝트입니다.  
현재는 **구현 전 문제 정의 단계(STEP 1~5)**까지 완료된 상태입니다.

---

## 프로젝트 한 줄 요약

> **4×4 격자에 놓인 1~16 배치가, 합의된 규칙(행·열·대각 합 34, 숫자 집합 제약)을 만족하는지 완전하고 재현 가능하게 판정하고, 위반 시 어떤 조건이 깨졌는지 구분할 수 있어야 한다.**

“마방진을 만드는 프로그램”이 아니라, **규칙 만족 여부를 판정·설명하는 문제**로 정의합니다.

## 배경 (왜 이 프로젝트인가)

### 다루는 상황

16개의 서로 다른 정수(1~16)를 4×4 격자에 배치했을 때, 정해진 **선**(행 4, 열 4, 대각 2) 위 숫자의 합이 모두 **34**가 되는지를 확인·설명해야 하는 상황입니다.

### 4×4를 선택한 이유 (관찰)

- 3×3보다 제약·연습 가치가 크고, 5×5보다 다루기 쉬운 규모
- “합이 같다”는 **불변 조건**이 명확한 고전 퍼즐
- 검증·규칙 명시화·역할 분리 등 **프로그래밍·설계 학습**에 적합한 최소 단위

### 1차 목적 (가정)

퍼즐·연습 문제의 **정답 검증** — 사용자가 채운 격자가 규칙을 만족하는지 판정하고, 틀렸을 때 **어느 조건이 깨졌는지** 구분해 알려 주는 것.  
특정 배치 하나와의 일치가 아니라, **규칙 충족 여부**가 성공 기준입니다.

## 표면 정의 vs 정확한 정의

### ❌ 표면 문제 (잘못된 정의)

> 4×4 마방진을 **만드는** 프로그램을 만든다.

생성·검증·표시가 한데 섞이고, “완성”과 “규칙 만족”이 구분되지 않습니다.

### ✅ 정확한 문제 정의

> 4×4 격자에 놓인 1~16 배치가, **행·열·대각**에 대해 합 **34**를 만족하고 **숫자 집합 제약**(각 수 1회, 범위 내)을 지키는지, **동일한 기준**으로 반복·완전·재현 가능하게 **판정**하며, 불만족 시 **깨진 조건을 구분**해 알려 줄 수 있어야 한다.

### 비목표 (현 단계)

- n×n 일반화
- 특정 “모범 답안” 격자와의 위치 일치
- 해 자동 생성·탐색 최적화
- UI·게임성 (별도 단계에서 검토)

## 핵심 Invariant (불변 조건)

### 대상(마방진)

| ID | 조건 |
|----|------|
| **I-1** | 격자는 4×4 |
| **I-2** | 1~16을 각각 정확히 한 번 사용 |
| **I-3** | 합의된 모든 선의 합 = **34** |
| **I-4** | 규칙을 만족하는 배치가 여러 개여도 동등하게 “정답” |

### 판정(검증)

| ID | 조건 |
|----|------|
| **V-1** | 정의된 검사를 **모두** 수행하기 전에는 통과 판정하지 않음 |
| **V-2** | 숫자 집합·범위·중복 위반은 합 오류보다 **우선 거부** |
| **V-3** | 동일 입력 → 동일 판정 (결정성) |
| **V-4** | “규칙 불만족”과 “판정 정보 부족(미완성)”은 **별도 결과** |

## 훈련하려는 사고 능력

구현 문법이 아니라, 아래 **사고 방식**을 기르는 것이 목표입니다.

- **규칙 명시화** — 모호한 말을 검사 가능한 조건으로 분해
- **경계·상태 구분** — 미완성 / 잘못된 입력 / 불만족 / 만족을 구분
- **완전성·일관성** — 확인 목록을 빠짐없이, 매번 같은 기준으로 적용
- **불변 중심 사고** — 합 34, 숫자 집합, 선 집합을 먼저 고정
- **계약·입출력 사고** — 판정 전에 입·출력과 실패 유형을 합의
- **검증 가능한 주장** — “잘 된다”를 구체적 통과·거부 사례로 표현

> 산술 속도가 아니라, **“무엇이 참이어야 하는가”**를 고정하고 일관되게 판단·설명하는 능력.
